Research contributions

Four threads of work. Each card names the problem, what I contributed, and the public outputs you can check.

  • 1. Evaluating real-time voice agents

    Problem: Voice-agent papers report incompatible metrics, so results can't be compared or reproduced. Contribution: A survey that connects component quality (speech recognition, latency, turn-taking) to grounded task outcomes. It proposes TRG (Timing-Recovery-Grounded), a minimum reporting standard, and ships a compliance checker and a baseline leaderboard.

    arXiv preprint · Dataset (DOI) · Code · Live demo

  • 2. Efficient small language models

    Problem: Large models are too slow and costly for many real-time language tasks. Contribution: Methods that make small models competitive: pruning, distillation, discriminative single-pass prediction, and TinyMorph, which curates training data using the model's own training trajectory instead of an external teacher.

    TinyMorph (code) · LLM from scratch

  • 3. Machine learning for health, accessibility, and public good

    Problem: High-stakes settings need models that are accurate, inclusive, and operationally useful. Contribution: Co-authored work on vision transformers for early oral-cancer detection (Springer), voice-biometric authentication designed for users with disabilities, and forecasting to reduce overcrowding at a public animal shelter (SMU Data Science Review).

    Oral cancer · Voice biometrics · Animal shelter

  • 4. Open, honest AI engineering education

    Problem: Learners rarely see AI systems that come with evaluations and documented failure modes. Contribution: Practical AI Systems is 30 standalone systems across three levels. Each has tests, a synthetic evaluation, written limitations, and an in-browser app, and the repo has a contributor process that checks every rule automatically.

    Repository · Live gallery · Extraction guides

Open-source software and models

Public, tested, and reproducible, so anyone can check the claims.

  • Practical AI Systems

    30 standalone AI systems at beginner, intermediate, and advanced levels: retrieval, extraction, guardrails, agents, and evaluation. Each has standard-library Python, tests, a synthetic evaluation, written limitations, and a zero-dependency web app.

    Try all 30 in the browser

  • Voice Agent Eval Corpus + TRG

    Companion software for the voice-agent survey: a 128-source corpus, the TRG compliance validator, and a baseline leaderboard. It's checked in CI and archived on Zenodo.

    Hugging Face Space · DOI

  • TinyMorph

    Self-improving training data for small language models through temporal weak-to-strong curation. It sorts examples into easy, ambiguous, hard, noisy, or memorized using the model's own training run.

  • Awesome Entity Extraction & Multimodal Extraction

    Curated, LLM-era guides to tools and models for entity, relation, and structured-data extraction from text and images. Every link is checked in CI.

  • Models on Hugging Face

    A vision-transformer cancer classifier, fine-tuned DistilGPT-2 and DistilRoBERTa language models, a sentiment model, and interactive Spaces.

  • GenAI Playlist

    Generative-AI fundamentals built from scratch: a GPT-style model in PyTorch, retrieval-augmented generation, and fine-tuning.
