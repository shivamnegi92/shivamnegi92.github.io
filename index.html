Flagship contribution

TRG: a reporting standard for real-time voice agents

Voice agents tend to report whichever metric flatters them. TRG asks every system to report on all the axes that matter, so results can be compared. I built the standard, a verified 128-source corpus, a validator, and a baseline leaderboard.

The TRG axes

From the TRG v2 specification

TTiming appropriatenessLatency with clock anchors and statistics, plus when it is appropriate to speak.
RRecoveryRestoring conversation and task state after a disruption, measured separately.
GGrounded outcomeExternally verified, authorized outcomes, including justified no-action.
MMultipartyConditional axis: appropriate speech and silence with several participants.

TRG baseline leaderboard

Grounded-outcome (G) score, as reported in each system's source benchmark

  • Nemotron VoiceChat*82.5%
  • xAI Grok Voice38%
  • OpenAI Realtime 1.535%
  • Gemini Live 2.526%

*Self-reported by the vendor; the others are third-party benchmarks. All four pass TRG compliance. The scores come from different benchmarks, so they show what each source reports rather than a head-to-head result. That gap is exactly what TRG is designed to close.
